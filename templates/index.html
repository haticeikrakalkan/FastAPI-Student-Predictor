Machine learning for education

Predict whether a student is likely to pass the course.

ScholarPath uses a logistic regression model trained on the UCI Student Performance dataset. It estimates pass or fail from school, family, study habits, and first-period grade (G1).

Open the predictor

What this tool does

Enter student background and first-period grade (G1). The model returns Pass or Fail (typically G3 ≥ 10). It is a decision-support tool, not a substitute for teacher judgment.

  • Target Pass / Fail classification
  • Input 31 features including G1
  • Data Portuguese secondary students (GP / MS)
